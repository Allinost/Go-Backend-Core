# Goodser UI Checklist / Phase UI-4 QA

> 适用范围：Web Goodser（商品、系列、组合包、捆、统计、订单、退货、入库、库存目录、设置）与小程序五 Tab 及创建/详情/营销/设置页。
> 使用方式：发版前按本清单逐项过一遍，自动化部分直接执行第 6 节脚本。

## 1. 通用检查项

### 1.1 状态

| # | 检查项 | Web | 小程序 |
|---|---|---|---|
| S1 | 首次加载有骨架屏或 loading，不出现空白闪烁 | 列表用 `NkLoading` | 列表用 `skeleton` |
| S2 | 加载失败有错误态与「重试」，重试可恢复 | 后端错误 toast + 可重试操作 | `error-state` + `bind:retry` |
| S3 | 无数据有空态，文案说明下一步 | `NkEmpty` | `empty-state` |
| S4 | 筛选无结果与「本来就没有数据」文案区分 | 退货/商品/事件已区分 | 搜索/筛选空态复用同一文案 |
| S5 | 提交中按钮 loading 且禁用，防重复提交 | `:loading` + `saving` | `submitting` + `btn-disabled` |
| S6 | 删除/取消等破坏性操作有二次确认 | 删除弹窗 | `wx.showModal` |
| S7 | 库存数值口径一致：可用 + 锁定 = 总量 | 商品卡/详情/统计 | 库存页统计栏/商品卡 |

## 7. 已知缺口

1. **可访问性**：NKUI Dialog/Drawer 已完成 `aria-modal`、焦点锁定与 Esc 关闭；仍缺表单 label 与控件关联、页面内纯图标按钮的可读名称。建议后续在 NKUI 表单组件与应用层逐步补齐。
2. **集成测试结果**：仅保存在浏览器 `localStorage`，换设备/清缓存后丢失；如需审计应落到后端。
3. **小程序未保存拦截**：已接入 `wx.enableAlertBeforeUnload`，创建成功后解除；若基础库不支持该 API 会静默跳过。
4. **组合包可售为 0**：Web 与小程序均已前置拦截（提示 + 禁用/阻止提交）。
5. **自动化时序**：`verify-orders-web.js` 已改为等待订单卡/捆预览渲染，连续执行稳定。
6. **视觉回归**：小程序目前只有数据级断言，未接入截图比对。
