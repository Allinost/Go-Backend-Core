# V3 评审清单

> 用于人工评审与 AI 子代理评审。所有项通过才允许合并。

## 1. 范围

- [ ] 只修改任务契约列出的文件/目录。
- [ ] 未修改 `zzz/goodser`、`zzz/ia`、`zzz/login3rd`、`zzz/shopchecker`。
- [ ] 未改变 `/api/v1` 契约（路径/请求/响应/错误码）。
- [ ] 未新增范围外依赖。

## 2. SQL / PostgreSQL

- [ ] 全部 `$n` 占位符，无 `?`。
- [ ] 无 `ON DUPLICATE KEY`、`JSON_CONTAINS`、`SHOW TABLES`、`SELECT DATABASE()`、反引号。
- [ ] JSONB/boolean/timestamptz/numeric 使用正确。
- [ ] UPSERT 使用 `ON CONFLICT`。
- [ ] 日期/分组/排序/NULL 语义正确。
- [ ] 动态 SQL 无注入风险；标识符已转义。
- [ ] 关键查询有索引；无 N+1/全表扫描。
- [ ] 事务边界合理；无长事务/外部 HTTP。

## 3. Schema / 迁移

- [ ] 新表/列有迁移。
- [ ] 迁移可重复执行、可回滚。
- [ ] 已发布迁移未被修改。
- [ ] 生产未依赖 AutoMigrate。
- [ ] 序列/外键/索引/注释/数据字典完整。
- [ ] GORM 模型与迁移一致。

## 4. 测试

- [ ] 单元测试覆盖核心逻辑。
- [ ] 仓库变更配 PG 集成测试/golden SQL。
- [ ] 迁移测试（up/重复/down）。
- [ ] 接口冒烟/回归。
- [ ] `go build ./...`、`go vet ./...`、`golangci-lint run`、`go test` 通过。

## 5. 安全 / 兼容

- [ ] 无密钥/Token/真实 `.env` 泄露。
- [ ] 权限/RBAC 正确；无越权。
- [ ] 日志不含敏感数据。
- [ ] 文件路径/上传/下载安全。
- [ ] 向后兼容旧客户端。

- [ ] 安全头、限流、上传限制、WebSocket 配置正确。

- [ ] 默认无自助注册；管理员授权流程可用。
