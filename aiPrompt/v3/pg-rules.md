# V3 PostgreSQL 速查规则

> 上游：[V3 SOP §6](../../docs/projects/go-backend-core/v3/SOP.md)

## 1. 占位符

- 一律 `$1..$n`；禁止 `?`。
- 动态 `IN`：生成连续 `$n`，或 `= ANY($1)`。
- 禁止 jsonb `?` 运算符；用 `jsonb_exists(col, $1)`。

## 2. 类型

| MySQL | PG |
|---|---|
| `BIGINT AUTO_INCREMENT` | `BIGINT GENERATED BY DEFAULT AS IDENTITY` |
| `TINYINT(1)` | `BOOLEAN` |
| `DATETIME` / `TIMESTAMP` | `TIMESTAMPTZ` |
| `JSON` | `JSONB` |
| `DECIMAL` | `NUMERIC` |
| `DOUBLE` | `DOUBLE PRECISION` |
| `UNSIGNED` | `CHECK (col >= 0)` |
| `ON UPDATE CURRENT_TIMESTAMP` | 触发器/应用层 |
| `ENGINE=...` / `utf8mb4` | 删除 |

## 3. 查询

| 场景 | 写法 |
|---|---|
| UPSERT | `ON CONFLICT (k) DO UPDATE SET c = EXCLUDED.c` |
| 忽略重复 | `ON CONFLICT DO NOTHING` |
| JSON 包含 | `tags @> $1::jsonb` |
| JSON 取值 | `col ->> 'key'` |
| 当前时间 | `now()` |
| 当前日期 | `CURRENT_DATE` |
| 加 N 天 | `d + make_interval(days => $1)` |
| 日期差 | `(a::date - b::date)` |
| 格式化 | `to_char(d, 'YYYY-MM-DD')` |
| 年份 | `EXTRACT(YEAR FROM d)` |
| 最新一行 | `DISTINCT ON (k) ... ORDER BY k, date DESC, id DESC` |
| 大小写搜索 | `ILIKE` |
| NULL 排序 | 显式 `NULLS FIRST/LAST` |
| 当前库 | `current_database()` / `current_schema()` |
| 表列表 | `pg_catalog.pg_tables` |
| 列信息 | `information_schema.columns`（小写列名） |
| 分页 | `LIMIT $1 OFFSET $2` |

## 4. GORM

- 驱动 `gorm.io/driver/postgres`；连接复用 `database.Main()` 的 `*sql.DB`。
- 生产 `auto_migrate=false`；启动校验 `_migrations`。
- 标签：`type:timestamptz`、`type:jsonb`、`type:numeric(18,4)`、`default:now()`。
- 表名显式 `TableName()`。
- UPSERT：`clause.OnConflict`。
- 错误：`TranslateError`。
- 复杂统计/窗口/JSONB：手写 SQL/pgx。
- 每个 Store 配 PG 集成测试。

## 5. 常见错误

| 错误 | 修复 |
|---|---|
| `WHERE id = ?` | `$1` |
| `enabled = 1` | `enabled = true` |
| `JSON_CONTAINS(tags, ?)` | `tags @> $1::jsonb` |
| `JSON_UNQUOTE(JSON_EXTRACT(col,'$.k'))` | `col ->> 'k'` |
| `CURDATE()` | `CURRENT_DATE` |
| `DATE_ADD(d, INTERVAL ? DAY)` | `d + make_interval(days => $1)` |
| `DATE_FORMAT` | `to_char` |
| `YEAR(d)` | `EXTRACT(YEAR FROM d)` |
| `MAX(CONCAT(date, LPAD(id,...)))` | `DISTINCT ON` |
| `SHOW TABLES` | `pg_catalog.pg_tables` |
| `SELECT DATABASE()` | `current_database()` |
| 反引号 | 双引号/全小写 |
| `LIMIT ?,?` | `LIMIT $1 OFFSET $2` |
| `GROUP BY` 缺列 | 补齐或窗口函数 |
| 序列未重置 | `setval` |
